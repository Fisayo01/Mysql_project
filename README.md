# SQL Project: Sales Data Analysis
## 📌 Project Overview
This project analyzes company sales performance using SQL and Excel to uncover key insights into revenue, profitability, product performance, and regional trends.
The analysis combines SQL-based data exploration with an interactive dashboard to provide a comprehensive view of business performance and support data-driven decision-making.

## 🎯 Problem Statement
The company generates significant sales revenue but lacks clear visibility into:
- Which products and regions drive the most revenue and profit.
- Sales team performance and contribution.
- Product demand patterns and order behavior.
- Profitability across products and sales channels.
- Opportunities to optimize pricing, inventory, and regional strategy.
- This project aims to answer these questions through structured data analysis and visualization.

## 🗂️ Dataset Description
The dataset contains transactional sales records with key fields:
- Order ID
- Product Name
- Product Category
- Sales Price
- Cost Price
- Profit
- Order Quantity
- Sales Channel (Distributor, In-store, Online, Wholesale)
- Sales Team
- Region / State

## ⚙️ Data Analysis Using SQL
The following business questions were answered using SQL:
- Revenue Analysis
- Sales Channel Filtering
- Sales Team Performance
- Order Behavior Analysis
- Top Products by Demand
- Regional Insights
- Specific Order Lookup
- Profitability by Region
- High-Value Sales Identification
- Product Category Performance
- Pricing Analysis
- Profitability Metrics

## 📊 Dashboard Overview
The Power BI dashboard provides a visual summary of key metrics:
### Key KPIs
- Total Revenue: $44.37M
- Total Cost: $31.69M
- Total Profit: $12.68M
- Total Orders: 20,000
- Total Quantity Ordered: 110,402

## Key Insights
1. Sales Team Performance
   - Nicholas Cunningham and other top salespeople generate the highest revenue.
   - Performance varies across team members, indicating opportunities for knowledge sharing.

2. Product Performance
    - Clocks category generates the highest revenue and profit.
    - Top ordered products show consistent demand patterns.

3. Revenue Trends
    - Revenue shows fluctuations, with a notable peak in May.
    - Indicates possible seasonality or campaign impact.

4. Regional Performance
    - Los Angeles County is the top-performing region.
    - Revenue is concentrated in a few key regions.

5. Sales Channel Distribution
    - Revenue is fairly distributed across channels.
    - Online and Wholesale channels present growth opportunities.

## 💡 Business Insights
- High-performing salesteam significantly influence revenue growth.
- Certain product categories consistently outperform others in both revenue and profit.
- Demand patterns suggest opportunities for inventory optimization.
- Regional concentration indicates potential for expansion in underperforming areas.

## 🎯 Recommendations
- Reward and Scale Top Sales Performance
- Replicate strategies used by top-performing salespeople.
- Optimize Product Strategy
- Focus on high-performing categories like Clocks.
- Improve Inventory Planning
- Stock high-demand products based on order trends.
- Expand High-Performing Regions
- Invest more in top regions like Los Angeles County.
- Enhance Sales Channels
- Explore growth opportunities

## 🚀 Project Outcome

This project demonstrates how combining SQL analysis with Power BI visualization can:

Transform raw data into actionable insights

Identify revenue and profitability drivers

Support strategic business decisions

Improve operational efficiency
